О музее

Музей программирования создан для тех, кто хочет понять не только «как писать код», но и «почему всё устроено именно так». Мы показываем эволюцию идей: от ламповых машин до нейросетей.

Особенность этой версии сайта: здесь нет JavaScript, поэтому голосовой помощник — это не работающий инструмент, а экспонат. Он показывает, как выглядели подсказки на ранних сайтах: просто текст, который всегда на экране.

Ключевые экспонаты (10 штук)

ENIAC (1945)

Один из первых электронных компьютеров. Занимал целую комнату, использовал тысячи ламп и программировался переключением проводов.

Fortran (1957)

Первый высокоуровневый язык программирования. До сих пор используется в науке и моделировании.

C (1972)

Язык, на котором написаны Unix и Linux. Понимание C помогает лучше понять, как работает компьютер.

Python (1991)

Простой и читаемый язык, который идеально подходит для старта. На нём удобно учиться логике и алгоритмам.

JavaScript (1995)

Язык веба. Позволяет делать страницы интерактивными: кнопки, анимации, формы и многое другое.

Git (2005)

Система контроля версий. Стандарт индустрии для совместной работы над кодом и хранения истории изменений.

Ada (1983)

Язык для надёжных систем (авиация, космос). Назван в честь Ады Лавлейс — первой программистки.

SQL (1974)

Язык запросов к базам данных. Без него не обходится почти ни одно приложение, где хранятся данные.

HTML (1993)

Основа веба: разметка страниц. Это не «программирование» в полном смысле, но без него нет сайтов.

CSS (1996)

Стили для веба. Делает страницы красивыми, адаптивными и удобными для пользователя.

Приветствие с проверкой возраста

Спрашивает возраст и по-разному здоровается. Тут есть if/else — как раз то, что ты учил.

age = int(input("Сколько тебе лет? "))
if age >= 16:
    print("Привет! Ты уже можешь участвовать в IT-проектах.")
else:
    print("Привет! У тебя отличный старт — учи базу.")
